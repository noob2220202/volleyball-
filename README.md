# 말랑배구 (MALLANG BEACH VOLLEY)

모찌(고양이)와 펭구(펭귄)의 레트로 픽셀 비치발리볼.
PC와 모바일에서 모두 돌아가고, **온라인 대전**을 중심으로 만들었습니다.

> 캐릭터, 배경, 공, 폰트, 효과음, 배경음악은 모두 코드로 직접 그리고 합성한 오리지널 리소스입니다.

## 실행

빌드 과정이 없는 정적 웹페이지입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

**GitHub Pages 배포:** 저장소 Settings → Pages에서 배포 브랜치를 고르면 바로 접속 주소가 생깁니다.

## 모드

| 모드 | 설명 |
|---|---|
| **빠른 대전** | 서버 없이 온라인 랜덤 매칭. 먼저 들어온 사람이 대기하고, 다음 사람이 자동으로 연결됩니다. |
| **방 만들기 / 방 참가** | 4자리 방 코드나 링크(`?room=CODE`)를 공유해서 친구와 대전합니다. |
| 연습 (vs CPU) | 난이도 3단계 |

## 조작

| | PC 키보드 | 모바일 |
|---|---|---|
| 이동 | A · D 또는 ← · → | ◀ ▶ |
| 점프 | W 또는 ↑ | 점프 |
| 스파이크 | Space · F · Enter | 스파이크 |

- 온라인 대전에서 방장은 모찌(왼쪽), 참가자는 펭구(오른쪽)를 맡습니다.
- **점프 중 스파이크**는 강타입니다. 방향키를 같이 누르면 궤도가 바뀝니다.
  - ↑ 높게
  - ↓ 내리꽂기
  - 네트 쪽 빠르게
  - 뒤쪽 짧게
- **점프 버튼 따닥**(두 번 빠르게)은 슬라이딩 리시브입니다. 방향키 방향으로 미끄러지고, 방향키를 안 누르면 공 쪽으로 갑니다.
- 모바일 버튼 배치: 왼쪽은 ◀ ▶, 오른쪽은 점프·스파이크입니다.
- 화면을 꽉 채웁니다. 화면 비율이 달라도 그림을 늘리지 않고, 해변과 하늘을 더 그려서 채웁니다.
  - 코트 양 끝은 깃발로 표시합니다.
  - 세로로 들고 게임을 시작하면 화면이 가로로 돌아가서 꽉 차게 나옵니다.

## 텔레그램 미니앱으로 띄우기

1. 게임을 HTTPS 주소로 배포합니다. GitHub Pages, Vercel, Netlify 어디든 됩니다.
2. [@BotFather](https://t.me/BotFather)에서 봇을 만듭니다.
   - `/newbot`으로 봇을 만들고, `/newapp`으로 미니앱을 등록합니다.
   - Web App URL에는 1번의 배포 주소를 넣습니다.
   - 미니앱 짧은 이름(예: `play`)을 정하면 `https://t.me/<봇이름>/play` 링크가 생깁니다.
3. `js/tg.js` 맨 위의 `TG_APP_URL`에 그 링크를 넣고 다시 배포합니다.
   - 예: `const TG_APP_URL = 'https://t.me/MallangVolleyBot/play';`
   - 이제 초대 링크가 `https://t.me/<봇>/play?startapp=방코드` 형태가 됩니다.
   - 친구가 링크를 누르면 텔레그램 안에서 바로 그 방으로 들어갑니다.
4. (선택) BotFather `/mybots` → Bot Settings → Menu Button에 같은 URL을 넣으면 채팅창 메뉴 버튼으로도 열 수 있습니다.

텔레그램 안에서 자동으로 적용되는 것:

- 전체 높이로 펼치기, 아래로 쓸어서 닫힘 방지, 노치·상단바 안전 영역 맞춤
- 텔레그램 **뒤로 버튼** 연동 (게임 중이면 일시정지 또는 나가기 확인)
- **친구 초대** 버튼이 텔레그램 공유 창(친구·채팅 선택)을 엽니다.
- 상대 이름 표시 (`vs 이름`)
- 진동 피드백: 리시브, 스파이크, 득점·실점
- 온라인 대전 중 창 닫기 확인, 전체화면 버튼 (Bot API 8.0+)

텔레그램 밖의 일반 브라우저에서도 그대로 동작합니다.

## 온라인 구조

- PeerJS(WebRTC)로 브라우저끼리 직접(P2P) 연결합니다. 별도 게임 서버가 필요 없습니다.
- 방장이 60fps로 물리를 계산해 상태를 보내고, 참가자는 입력만 보냅니다(호스트 권한 방식). 그래서 두 화면이 어긋나지 않습니다.
- 참가자 화면은 내 캐릭터에 클라이언트 예측을 적용해서 핑이 있어도 즉시 반응합니다.
- 핑 표시, 재경기(양쪽 동의), 끊김 감지(7초 무응답)를 지원합니다.

## 파일

```
index.html      화면 / 메뉴
style.css       레트로 UI, 터치 버튼
js/game.js      물리·규칙 시뮬레이션
js/ai.js        CPU
js/render.js    픽셀아트 렌더링, 이펙트
js/font.js      3x5 비트맵 폰트
js/audio.js     칩튠 효과음·BGM (WebAudio)
js/input.js     키보드·멀티터치
js/net.js       온라인 (PeerJS)
js/tg.js        텔레그램 미니앱 연동 (TG_APP_URL 설정)
js/main.js      게임 루프, 화면 전환, 온라인 동기화
```
